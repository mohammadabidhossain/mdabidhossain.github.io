Selected work

A closer look at how I approach real network and automation problems — the situation, what I built, and what changed as a result.

01
Problem

A mixed Juniper and Palo Alto environment needed consistent, hardened site-to-site connectivity without relying on ad-hoc, per-site configs that were hard to audit or reproduce.

What I built

Designed and deployed standardized IPsec site-to-site VPN topologies across Junos OS and PAN-OS devices, with hardened firewall policy and consistent security-zone segmentation across sites.

Outcome

A repeatable VPN design pattern that's faster to roll out to new sites and straightforward to audit for security posture.

Junos OS PAN-OS IPsec Firewall Policy
02
Problem

Provisioning and configuration changes had to reach devices sitting behind multiple SSH bastion hops, which made manual rollouts slow and error-prone at any real scale.

What I built

Python and Bash tooling — using Expect/TCL and multi-hop SSH — to chain through bastion hosts and push configuration changes to Junos and Palo Alto devices consistently, with the same logic reusable across jobs.

Outcome

Removed the manual, hop-by-hop SSH work from routine provisioning, cutting the chance of a missed step or inconsistent config.

Python Bash Expect / TCL Multi-hop SSH
